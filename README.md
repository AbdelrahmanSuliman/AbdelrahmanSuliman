## Highlights

### Fullstack Projects

These are projects built purely for fun and learning!

- **Quittr Accountability Platform**  
  A full-stack accountability tracking platform with partner invitations, habit calendars, daily journaling, and secure authentication.  
  **Tech:** React, Node.js, TypeScript, PostgreSQL, Drizzle ORM, Docker  
  **Live:** [Demo](https://app.quittr.site/)  
  **Repo:** [GitHub](https://github.com/AbdelrahmanSuliman/Quittr)

- **ATLUS Secure E-Commerce Platform**  
  A secure e-commerce platform with Stripe payment processing, webhook verification, product management, and protected API routes.  
  **Tech:** Next.js, Node.js, TypeScript, PostgreSQL, Prisma, Stripe, AWS S3  
  **Live:** [Demo](https://atlus-frontend.vercel.app/)  
  **Repo:** [GitHub](https://github.com/AbdelrahmanSuliman/ATLUS)

- **LeetNote AI-Powered LeetCode Assistant**  
  A desktop app that helps track LeetCode progress, organize problem notes, and generate AI-powered complexity analysis and optimization hints.  
  **Tech:** React, TypeScript, Electron, Express, Prisma, SQLite, Gemini  
  **Repo:** [GitHub](https://github.com/AbdelrahmanSuliman)
